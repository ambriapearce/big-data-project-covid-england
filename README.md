# COVID-19 Data Visualisation in England.

This project uses **Tableau** to analyse and visualise daily COVID-19 cases and hospital admissions across regions of England.

The analysis explores temporal and geographic patterns in COVID-19 activity, with interactive filters allowing users to examine trends across individual regions.

---

## Project Objectives

The visualisation was designed to:

- Explore changes in reported COVID-19 cases over time.
- Examine patterns in hospital admissions across English regions.
- Compare regional differences in COVID-19 activity.
- Identify periods of increased cases and hospital admissions.
- Provide an interactive way to explore regional and temporal trends.

---

## Technologies and Data

- **Tableau** - data processing, analysis and interactive visualisation
- **Microsoft Excel** - supporting data preparation
- **NHS regional data** - hospital admissions across English regions
- **COVID-19 case data** - reported cases by region and specimen date

## How to Open 👩🏾‍💻

2. Open **24COP511_COVID_Visualisation.twbx**
